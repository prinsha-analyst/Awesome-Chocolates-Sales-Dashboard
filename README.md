# Chocolate Sales Dashboard – Power BI

## Project Overview

This project focuses on analyzing chocolate sales data and presenting meaningful business insights through an interactive Power BI dashboard. The dashboard helps visualize sales performance, identify top-selling products, and understand regional sales distribution.

The goal of this project is to transform raw sales data into actionable insights using data visualization techniques.

## Dataset

The dataset contains sales information related to chocolate products. It includes details such as product names, sales amount, region, and transaction-level data.

Dataset file: `Awesome-chocolates-dataset.xlsx`

## Dashboard Features

The Power BI dashboard provides several insights including:

* Total sales performance
* Top selling chocolate products
* Sales trends over time
* Region-wise sales comparison
* Product category performance
* Overall sales distribution

## Tools and Technologies Used

* Microsoft Power BI
* Microsoft Excel
* Data Visualization
* Business Intelligence Reporting
